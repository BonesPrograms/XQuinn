Yes. You can create an IL2CPP-injected type and instantiate an IL2CPP object from it. My previous statement that your mod type could not become an IL2CPP type was wrong.

With an IL2CPP interop framework, the exposed registration method is typically:

csharp

Copy


ClassInjector.RegisterTypeInIl2Cpp<MyType>();
After registration, MyType has an IL2CPP class representation and can be used as an IL2CPP object, subject to the framework’s inheritance and constructor requirements. It is no longer merely an ordinary mod-side managed type.

The important distinction is:

An ordinary mod class remains a managed .NET type.
A class registered through ClassInjector.RegisterTypeInIl2Cpp<T>() becomes an injected IL2CPP type.
Instances of that registered class can be created as IL2CPP objects and passed through IL2CPP APIs.
The class must follow the injector’s requirements, such as deriving from an allowed IL2CPP base type and providing the required constructor pattern, commonly a constructor accepting IntPtr for IL2CPP-created instances.
So the accurate answer is: yes, you can make your own type an IL2CPP type and create an IL2CPP object from it through type injection.
