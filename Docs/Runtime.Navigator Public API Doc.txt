Runtime Navigator public API documentation
=========================================

The maintained, formatted guide is now Runtime.Navigator.md in this directory.
Open it in a Markdown preview to see the tables, source references, and verified
runtime screenshots.

Related documentation:
  README.md             Documentation index and screenshot rules
  Runtime.Navigator.md  Navigator setup, commands, references, and limitations
  TypeRegister.md       Type registration, lookup, and naming rules

Important corrections to the former text guide:
  $ loads a static type; @ is only used for no-escape string literals.
  # and * both load instances.
  Semicolon chains are automatic; the ~ controller is no longer used.
  +name = expression creates or replaces a reference, subject to loaded-reference
  and nullability restrictions. References are not immutable.
  The first method overload has an unsuffixed key; later keys use :1, :2, etc.
  DeclaredOnly is not part of the default query mask.
  Types.String, Types.Cast, and Types.LateCache are not current helper methods.

The formatted guides link directly to the source files that define each rule.
